Privacy Policy Effective Date: 06/03/2025 1. Introduction Thank you for using Pinterest Fashion Trend Checker (the "Extension"). Your privacy is important to us. This Privacy Policy explains what data we collect, how we use it, and your rights regarding that data. 2. Data Collection & Usage This Extension does not collect, store, or share any personal data. It only interacts with the Pinterest API to fetch fashion trend information based on the items you browse while shopping online. The extension does not track your browsing history or store any user information on external servers. 3. Permissions This Extension requires the following Chrome permissions: activeTab – To detect clothing-related text on shopping websites. scripting – To insert the trend-checking functionality into webpages. storage – To temporarily store trend data for a better user experience. These permissions are only used to provide the core functionality of the extension and are not used for tracking or analytics. 4. Third-Party Services This Extension communicates with Pinterest's API to fetch trending fashion-related data. All API requests are made directly from the user's browser. We do not have access to or store Pinterest account details. For more information on how Pinterest handles your data, please review Pinterest’s Privacy Policy. 5. Data Security We do not collect sensitive user data. All API interactions are performed securely within the extension itself. 6.
